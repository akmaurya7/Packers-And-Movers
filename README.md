# KGF Express Packers & Movers — Web Application

> Premium, minimal, and mobile-friendly web application for **KGF Express Packers and Movers** (Electronic City, Bengaluru). Inspired by Crestfold Moving Company's editorial design language with 3D logistics visuals, an interactive Move Size Estimator, Leaflet map location picker, and automated WhatsApp quote dispatching.

---

## 🚚 Features

- **Crestfold Editorial Design:** Warm textured paper (`#FAF7F2`), ink typography (`#191817`), and moving orange accents (`#E8590C`).
- **3D Render Visuals:** Bespoke 3D isometric models of logistics fleets, brand monograms, and 5-layer packed residential interiors.
- **Move Size Estimator:** Interactive inventory calculator for 1 BHK, 2 BHK, 3 BHK, 4+ BHK / Villa, Office, and Vehicle relocations.
- **Dynamic Warehousing Flow:** When *Warehouse & Storage* is selected, destination fields are automatically hidden, prompting only for current pickup location and storage duration.
- **WhatsApp Dispatch Engine:** Formats quotations in clean WhatsApp markdown without broken glyphs, opening direct communication with dispatch on `+91 73385 82679`.
- **Interactive Map Picker:** Leaflet + OpenStreetMap pin picker with reverse geocoding and device GPS auto-detection.
- **SEO & Google Rich Results:** Complete `Schema.org` JSON-LD (`MovingCompany`, `LocalBusiness`, `FAQPage`), XML sitemap, and robots.txt.

---

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Custom Vanilla CSS Design System
- **Icons:** Lucide React
- **Mapping:** Leaflet & OpenStreetMap (Nominatim Reverse Geocoding)
- **Deployment:** Static Build / Vercel / Netlify / GitHub Pages ready

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
Production output will be generated in `dist/`.
